# Athalla audio guide

Audio is optional. The app works entirely with Malayalam subtitles if files are absent. Add local files in this folder and update `audioMap` in `static/js/script.js`.

Suggested filenames:

- `opening-instruction.mp3`: opening room introduction
- `wrong-01.mp3` through `wrong-06.mp3`: wrong reactions
- `accept.mp3`: ഹാ, അതുതന്നെ! ഇതെടുക്കാനാണോ ഇത്ര പാട്?
- `takeover-scold.mp3`: നിന്നെ കൊണ്ട് ഒരു ഉപയോഗവും ഇല്ല!
- `takeover-point.mp3`: ഇതല്ലേ ഇവിടെ ഇരിക്കുന്നേ!
- `takeover-pickup.mp3`: ഇത് തന്നെയല്ലേ ഞാൻ പറഞ്ഞത്!

Only add recordings whose spoken words match the visible subtitle. Missing or unsupported files are ignored.
